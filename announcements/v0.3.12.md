# reinhardt-web v0.3.12

## Highlights

This release fixes a functional bug affecting `ModelViewSet` custom lookup fields. Previously, configuring `with_lookup_field` only changed the detail route's URL parameter name — the underlying retrieve, update, and destroy handlers still treated the extracted value as a primary key, causing custom-field lookups to incorrectly return `NotFound`. This is now corrected: custom lookup values are properly mapped through model field metadata, producing typed bindings and correct physical column matches for both in-memory and database-backed detail queries. The fix applies consistently across retrieve, update, destroy, and `ReadOnlyModelViewSet` retrieve operations, including row-lock rechecks performed during mutations, with no additional query overhead introduced.

Additionally, this release restores a healthy CI Security Audit by updating the `cargo-deny` duplicate-version policy to allow the currently compatible `darling` (0.23–0.24) and `prettyplease` (0.2–0.3) dependency ranges, which had begun appearing as duplicates in the full-feature workspace dependency graph.

## Breaking Changes

No breaking changes in this release.
