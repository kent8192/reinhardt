# reinhardt-web v0.3.4

## Highlights

This release focuses on two targeted bug fixes. The CI auto-fix workflow for GraphQL schemas now streams staged additions through `base64` and `jq` rather than passing file contents as command-line arguments, preventing large style fixes from exceeding process argument limits and ensuring the auto-fix commit exactly matches the staged patch. A regression guard and documentation covering the payload-size guarantee accompany this fix.

On the ORM side, `Manager::delete_with_conn` now resolves a model's primary key column via `field_metadata()` before building deletion SQL, instead of relying on the Rust field name and guessing the bound value type from `Display` output. This fixes cases where `db_column` aliases could cause deletions to target the wrong column and where typed primary-key representations (e.g., a numeric-looking string ID) could be silently coerced incorrectly. The fix reuses `Model::primary_key_filter_value()` and existing QuerySet binding conversions, and is backed by new regression tests covering PostgreSQL, MySQL, and SQLite with an aliased custom typed primary key.
