# reinhardt-web v0.3.8

## Highlights

This release includes an important security fix for the model `Info` DTO generation. Previously, fields annotated with `#[field(skip_getter = true)]` were incorrectly included in generated `{Model}Info` structs, meaning sensitive state — including authentication and privilege flags injected via the `#[user]` macro — could be exposed through public DTOs and potentially written back via mass-assignment when converting an `Info` back into a `Model`. This has been fixed by restoring the `skip_getter` exclusion in the Info-field selection logic, with new integration tests confirming that such fields no longer serialize into `Info` JSON and that round-tripping now yields safe defaults instead of permitting assignment. Documentation in `MACRO_USAGE.md` has been updated to reflect this secure behavior.

On the infrastructure side, this release resolves a dependency conflict between `num-bigint` versions required by different backends (Cassandra via `bigdecimal` on 0.4.x and Redis on 0.5.x), allowing both to coexist without triggering the workspace's duplicate-version policy checks. Additionally, the CI coverage pipeline has been hardened to fail closed: each test suite now validates its own non-empty LCOV report before publishing, and the aggregate coverage job validates the full combined report rather than allowing partial or empty coverage results to pass silently. This improves confidence in the project's test coverage signal going forward, alongside new tests covering the database AST parser's fallback behavior.
