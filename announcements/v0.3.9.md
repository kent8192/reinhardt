# reinhardt-web v0.3.9

## Highlights

This release fixes an important data-safety issue in `ModelViewSet`: database-backed list, retrieve, update, and destroy operations previously loaded the full table into memory via `Session::list_all()` and searched in-process, which allowed detail routes to read or mutate records outside an application-defined request scope. These paths now execute filtered `QuerySet` predicates directly in SQL, respecting custom manager predicates and typed primary-key lookups while keeping existing `Vec`-based querysets compatible. Building on this, `QuerySet::delete_query` and `update_fields` now reject tautological `WHERE` clauses — including empty `AND` compositions and empty `NOT IN` collections — preventing accidental full-table deletes or updates.

Serializers gain presence-aware JSON extraction (`Absent`/`Null`/`Present(T)`) across all built-in fields, aggregated `{field: [messages]}` error reporting, and a new `FieldWithErrorMessages` adapter that lets applications supply custom or localized error message closures for character, numeric, email, URL, choice, date, and datetime fields without abandoning the structured `FieldError` variants.

On the security-hardening side, this release removes several vulnerable dependency paths from the workspace: the legacy `cloud-storage` GCS client (`ring 0.16`, RUSTSEC-2025-0009) is replaced with `google-cloud-storage`, `rskafka` is upgraded to 0.6 for `rustls-webpki 0.103`, and the optional Azure staticfiles backend now speaks the Blob REST API directly with SharedKey/SAS signing, dropping the vulnerable `quick-xml 0.31` dependency chain (RUSTSEC-2026-0194/0195) — all with unchanged public APIs. The admin interface also gains correct conversion for new `FilterValue` temporal and decimal variants.

Alongside these fixes, the release adds an extensive, boundary-by-boundary security policy hierarchy (root plus 17 component policies) documenting Reinhardt's trust boundaries, threat model, and invariants for reviewers and integrators.

## Breaking Changes

No breaking changes in this release.
