# reinhardt-web v0.4.0-alpha.11

## Highlights

This release ships an important security fix: a vulnerable, inactive `rkyv 0.7` dependency pulled in transitively via `rust_decimal` is patched by pinning to a reviewed upstream Git commit that removes it (RUSTSEC-2026-0235). This is a temporary measure until `rust_decimal 1.43.0` is published on crates.io with the upstream fix, but it eliminates the vulnerable dependency from the resolved dependency tree in the meantime.

Two Azure blob storage hardening fixes land as well: generated blob URLs are now confined to their intended scope, and requests containing dot segments in blob paths are rejected outright, closing off a class of path-traversal risk in the Azure storage backend.

On the Pages side, `ClientForm::submit` now generates with a target-neutral signature shared between native SSR and WASM builds. Previously, components needed separate native and WASM action closures because the generated submit function only existed for WASM targets. Now, `use_action` call sites compile once across both targets while execution and structured error routing remain WASM-only — native builds only gain a type-checking surface, with no runtime behavior change.

Additionally, a redundant rustdoc link target in the database docs is cleaned up, and this release also forward-merges `main` (including the stable 0.3.11–0.3.13 line) into the `develop/0.4.0` branch, reconciling formatter, Azure static-files, and ModelViewSet changes while preserving the newer scoped querying and mutation-safeguard behavior on this release line.

## Breaking Changes

No breaking changes in this release.
