# reinhardt-web v0.4.0-alpha.13

## Highlights

This release focuses on hardening the plugin loading system in `dentdelion`, with a cluster of fixes that confine plugin loading to its root directory, close a path-related race condition, retain the plugin root capability, and preserve anchored loader behavior. Together these changes tighten the security boundary around plugin discovery and loading.

On the security front, the middleware layer now prevents private cache replay, closing a gap where cached private responses could be inadvertently served to unintended requesters.

The Admin interface receives several correctness fixes: object-scoped querysets are now consistently applied across edit forms, relation targets, and history endpoints, ensuring deleted or out-of-scope objects are properly excluded; aliased edit-form values are preserved after physical-to-logical field translation, fixing a bug where relation edit values could be silently dropped; and the `core` crate now correctly enables security when the `page` feature is active.

Finally, this release includes native build fixes for `reinhardt-utils`, gating an async filesystem import behind the correct target configuration and qualifying a filesystem test helper so that native (non-WASM) builds compile and test cleanly.

## Breaking Changes

No breaking changes in this release.
