# reinhardt-web v0.4.0-alpha.7

## Highlights

This release delivers a major expansion of the admin panel, bringing it much closer to feature parity with mature Python admin tooling. `ModelAdmin` now supports ordered fieldsets, inline editing for both changelist rows and related models, many-to-many selector widgets, autocomplete/raw-ID relation fields, custom bulk actions, request-scoped changelist queries with foreign-key joins, per-object change history, and general form customization via typed adapters — all opt-in and backward compatible unless noted below.

On the ORM side, the string-based aggregate/annotation API is replaced by a fully typed `func::*` expression system with typed HAVING clauses and cross-backend decoding (PostgreSQL, MySQL, SQLite). The JSONB type identifiers are renamed for naming consistency (`JsonBinary` → `Jsonb`). A new storage-backed `FileField`/`ImageField` foundation adds transaction-aware multipart upload handling with compensation and cleanup across local, S3, GCS, and Azure backends.

On the Pages side, this release adds ergonomic named-route navigation with hard-fallback semantics, a configurable query retry policy with exponential backoff, and an opt-in normalized entity cache for Query Client V2. The task worker now runs genuinely concurrent consumer loops with atomic SQLite job claiming and race-free shutdown. Generated projects gain native gRPC/WebSocket route launching via `manage runserver`, plus new `manage contract export` and `manage verify` commands for deterministic, machine-readable application contract validation.
