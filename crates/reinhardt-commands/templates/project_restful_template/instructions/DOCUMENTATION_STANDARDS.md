# Documentation Standards

- Update documentation in the same change as commands, layout, settings, or runtime behavior.
- Use `README.md` for setup, commands, project structure, and runtime behavior.
- Use `instructions/` for durable engineering rules and keep its references valid.
- Write code comments and rustdoc in English.
- Keep examples aligned with `Cargo.toml`, `Makefile.toml`, and the generated REST layout.
- Do not document private credentials, user requests, or assistant interactions.
- Use language tags in code fences and keep documented commands executable.
